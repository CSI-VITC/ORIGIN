# CSI ORIGIN 2026

The official hackathon landing page for **CSI ORIGIN 2026**, hosted by the Computer Society of India (CSI) Student Chapter at VIT Chennai.

## Overview
This is a modern, high-performance Next.js web application built with:
- Next.js 15 (App Router)
- React 19
- Tailwind CSS
- Framer Motion & GSAP for animations
- Three.js / React Three Fiber for 3D elements

## Run Locally

**Prerequisites:** Node.js

1. Clone the repository and install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.
